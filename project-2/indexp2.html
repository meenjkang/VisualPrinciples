Project 2: Book to Website

This project is an interactive website that reinterprets a literary text into a website. Inspired after reading John Berger’s book ‘The Red Tenda of Bologna’, it explores the tactile aspect of memory through randomized elements and a linear structure that returns to the start when one cycle of the book is finished. The website navigates through the user finding the 'Bologna Red' color on the screen, thus adding a gamelike and ambiguous quality to it. Simultaneously, my hand-drawn illustrations and interactive elements in the website create a sense of rawness and nonlinearity, which ultimately mimics the way a memory is formed.
