Project 3: Standby Mode

This project reimagines Apple's Standby mode by integrating a dynamic gradient background that changes to reflect the natural progression of the day from sunrise to sunset and into the evening. The interface pairs essential data like time, date, and temperature with a box breathing border designed to help users calm down and practice mindfulness.
